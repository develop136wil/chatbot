최신 인덱싱 복구·오프라인 요청 보완과 141개 테스트 결과는 [후속 기록](indexer-recovery.md)을 참고하세요.

작업일: 2026-09-20
브랜치: `codex/no-sql-ui-observability-20260920`
대상: `develop136wil/chatbot`만 수정

## 구현 내용

### 오류와 빈 결과 구분

- 검색 연결 실패·임베딩 불가를 정상적인 빈 검색 결과와 구분합니다.
- 카테고리 검색 실패 후 전체 검색이 성공하는 기존 복구 경로는 유지합니다.
- 전체 검색까지 실패하면 오류로 전달합니다. 일부 결과만 있는 상태를 완전한 결과로 캐시하지 않습니다.
- 직접 실행과 Redis 작업 모두 실패를 status=error로 반환합니다.
- 결과 포맷팅 실패도 정상 답변으로 저장하지 않습니다.
- 빈 결과는 응답 캐시에 새로 저장하지 않습니다.
- 기존 Supabase 응답 캐시에 남아 있을 수 있는 알려진 빈 결과·오류 문구를 조회 시 제외합니다.
- 정상 답변 캐시의 키·버전·TTL은 그대로 유지하며 DB 데이터를 삭제하지 않습니다.

### 사용자 안내와 조작

- 실제 단계와 무관하게 순환하던 대기 문구를 중립적인 검색/대기 안내로 바꿨습니다.
- 로고 화면의 강제 대기와 완료된 텍스트의 인위적인 타이핑 지연을 제거했습니다.
- 오류 시 원래 질문과 문맥을 보존하는 수동 재시도를 제공합니다.
- 자동 재시도는 추가하지 않았습니다. 연속 클릭과 오래된 오류 버튼의 재전송을 방지합니다.
- HTTP 429는 일반 장애와 구분하고 Retry-After가 있으면 대기 시간을 적용합니다.
- 확인되지 않은 공급자 제한을 '오늘 한도 소진'이라고 단정하지 않습니다.
- 공급자 제한/일일 제한에는 즉시 재시도 버튼을 표시하지 않습니다.
- 공유창 취소 시 복사하지 않습니다.
- 중복 토스트 함수와 숨겨진 부모 영역 스타일을 정리했습니다.

### 첫 화면·언어

- '도봉구 영유아 복지톡'으로 대표 이름을 정리했습니다.
- 개인정보를 요구하는 대신 질문 예시와 선택적인 개월 수 안내를 제공합니다.
- 화면 문구를 static/ui-text.js의 4개 언어 사전으로 모았습니다.
- 공유·네트워크 상태·접근성 이름·최신 답변 이동 문구를 현지화했습니다.
- 언어 선택을 브라우저에 저장하고 새로고침 후 복원합니다.
  저장소가 차단되거나 값이 잘못돼도 기본 언어로 동작합니다.
- 언어 선택을 국기 대신 언어명으로 표시하고 상단 별도 영역에 배치했습니다.
- 상단 영역과 하단 입력 영역 높이를 측정해 답변 공간을 확보합니다.
- 언어 변경은 다음 답변부터 적용된다는 안내를 제공합니다.

### 카드 정보

- 기존 요약 내용과 순서는 보존합니다. 검색·랭킹·모델·임계값은 바꾸지 않았습니다.
- '자세히 보기'를 '자료 원문 보기'로 명확히 표시합니다.
- 실제 last_edited_time이 유효할 때만 자료 수정일을 표시합니다.
- 자료 수정일이 정책 시행일과 다를 수 있음을 함께 알립니다.
- 최종 지원 조건과 신청 방법은 원문 및 담당 기관에 확인하도록 안내합니다.
- 실시간 번역이 꺼진 상태에서 번역 자료가 없으면 한국어 원문 표시 사실을 알립니다.
- 원본 메타데이터를 변형하지 않도록 복사 후 화면 언어를 적용합니다.
- 실시간 번역이 꺼져 있는데도 번역 코루틴부터 생성하던 부분을 정리했습니다.

정상 캐시를 강제로 비우지 않았으므로 기존 캐시 카드에는 날짜·번역 안내가 없을 수 있습니다.
버튼 명칭은 화면에서 갱신하지만, 추가 메타정보는 새로 조립되는 카드부터 적용됩니다.
이를 위해 전체 재색인이나 일괄 AI 재호출을 하지 않습니다.

## 배포 전 오프라인 통합 검증 (2026-09-20 후속)

추가 통합 테스트 3개를 작성했으며 운영 코드는 변경하지 않았습니다.
