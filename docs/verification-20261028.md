## 발견된 표시 오류

`utils.clean_summary_text()`가 목록 기호를 제거할 때 숫자까지 제거한다.

```text
원본: - 123,456 KRW 지급 (가상 테스트)
카드: ,456 KRW 지급 (가상 테스트)

원본: - 24~35개월 도봉구 거주 아동만 (가상 조건)
카드: ~35개월 도봉구 거주 아동만 (가상 조건)
```

원인 정규식은 `^[\s\*\-•①-⑮❶-❿0-9\.]+\s*`이다. 목록 번호와 실제 수치가 구분되지 않는다. 이후 `len(clean_line) > 5` 조건 때문에 잘린 짧은 값은 줄 전체가 사라질 수도 있다. 원본 메타데이터는 정상이며, 표시·공유 텍스트를 구성하는 단계의 문제다.

실제 저장 자료에서도 다음 사례를 확인했다.

- 자료: **아이돌봄서비스 - 질병감염아동지원**
- page_id: `2738ade5-0210-812a-9c63-f9b330dc3fc1`
- 저장 요약의 별도 줄: `15,340원`
- 수정 전 정리 함수의 결과: 해당 금액 누락.

이는 저장 자료와 코드 출력의 비교이며, 해당 요금이 현재 정책상 맞는지를 확인한 것은 아니다. 실제 이용자에게 이 오류 답변이 제공된 횟수는 확인하지 않았다.

숫자로 시작하는 금액·월령 줄을 대상으로 한 제한적인 전수 탐지에서는 한국어 1건, 영어 3건, 베트남어 1건이 손실 의심 대상으로 나왔다. 언어별 중복 문서가 있을 수 있으며 이 수를 고유 문서 수나 전체 오류 수로 합산하면 안 된다. 탐지식이 잡지 못한 다른 표현도 있을 수 있다.

## 남은 검사와 권장 순서

1. **로컬 수정·회귀 검사 완료.** 배포는 별도 승인 후 진행한다. 캐시 버전 변경에 따른 최초 재검색을 고려한다.
2. 무료/0원, 범위·소수·음수, 짧은 조건, 4줄 이후 항목을 검증했다. 기존 섹션 선택·숨김 키워드 정책의 의미 손실 가능성은 별도 평가 대상으로 남긴다. 모든 문장이 보존된다고 주장하지 않는다.
3. 실제 AI 검사는 승인 후 재시도 포함 최대 25회로 제한한다. 공개 지원사업의 5개 언어 검색·원문 비교와 가상 신규 문서 번역을 검사한다. DB·캐시·통계 쓰기와 인덱싱은 금지한다.
4. 실제 답변 평가는 관련 문서 검색 여부뿐 아니라 금액·통화·월령·거주지·예외 조건·원문 링크를 비교한다. 필드 존재/HTTP 200/모델 응답 성공만으로 정확성을 판정하지 않는다.

실제 신규 문서의 운영 DB 저장은 이번 검사 범위에 포함하지 않았다. 기존 예약 실행에서 155건이 모두 건너뛰어졌던 결과는 예약 운영 확인이며 신규 번역 품질의 증거가 아니다. 원어민 수준의 자연스러움, 모든 실제 기기·브라우저, 정책 최신성까지 보장하지 않는다.
