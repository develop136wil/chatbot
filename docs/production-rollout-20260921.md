# Production 반영 기록 (2026-09-21)

## 범위와 승인

사용자 요청: "그냥 Production에 반영해줘."
SQL-free 검증 브랜치의 변경 및 마지막 팁 디자인 수정을 main에 반영한다.
새 SQL, 비밀키 교체, Vercel 환경변수 변경은 포함하지 않는다.

## 복구 기준

반영 전 운영 main: 2b4eddb48771f8e21615baa654e88db17f506f0c.
문제 발생 시 이 커밋의 배포로 복구하거나, 해당 트리로 되돌리는 새 커밋을 만든다.
공유 main에 강제 push/reset은 하지 않는다.

## 마지막 수정

- 스켈레톤을 원본 3줄(90%/70%/85%)로 복원.
- 진행 문구 14px/600/#333, 팁 12px/400/#888/줄높이 1.6.
- 원본 여백을 복원하고 일반 문단 CSS보다 구체적인 선택자로 보호.
- 문자열 null/None/undefined/빈 카테고리를 실제 None으로 취급.
  정상 카테고리는 유지하고 불필요한 필터 RPC를 생략한다.
- 랜덤 팁, 취소/타임아웃, 오류 복구, 무료 한도 방어는 유지.

## 검색 0건 원인 확인

사용자가 SUPABASE_KEY 적용 환경이 Production만이라고 확인했다.
같은 프로젝트의 기존 로컬 서버 키로 HEAD 조회 시 문서 155개를 확인했다.
Preview의 0개 결과는 실제 DB 전체 삭제가 아니며 Preview의 인증/권한 차이가 있다.
Production 배포 후 실제 검색을 별도로 확인해야 한다.
