# UI/UX 디자인 보존 검토 - 2026-09-21

## 결론과 범위

기존 UI를 새 테마로 교체하지 않고 디자인 기준을 명문화했다.
이전 턴의 미배포 변경(첫 안내 문의 제거, 문구 정리, 회색 결과 더 보기, 문의 앞 구분선)을 보존했다.
검색·캐시·임베딩·AI 제한·Notion·Supabase·통계 백엔드·SQL은 수정하지 않았다.
이 문서는 로컬 검증 결과다. 운영 배포 성공 또는 실제 사용자의 평가 결과가 아니다.

외부 자료는 지침으로 읽고 현재 HTML/CSS/JavaScript와 대조했다.

DESIGN.md는 규격의 YAML 토큰과 섹션 순서를 참고한 프로젝트 기준 문서다.
공식 linter 통과나 스킬 인증을 주장하지 않는다.

외부 지침 중 네이티브 앱 전용 수치, 다크 모드 도입, 모든 이모지/PNG 교체,
새로운 React/Tailwind/GSAP 도입은 이 프로젝트에 그대로 적용하지 않았다.

## 문제별 처리

| 항목 | 변경 전 근거 | 처리 | 확인 |
|---|---|---|---|
| 디자인 기준 부재 | UI 선택이 코드와 대화에 흩어져 있음 | DESIGN.md 및 AGENTS.md 참조 규칙 추가 | 캐릭터·국기·폰트·글라스·밝은 모드·버튼 원칙 명문화 |

## 검증 방법

### 단위 회귀

node --test tests/frontend.test.cjs tests/analytics_dashboard.test.cjs

다국어 버튼 클릭, 캐시 답변 후처리, 오류/재시도, 문의, 개인정보 미첨부,
통계 요청 ID, 동작 줄이기 타이머·리스너 정리, 키보드만 스크롤하는 조건을 검증한다.

### 실제 브라우저 레이아웃

node tests/ui_design.browser.cjs

- 수정 전 재현: --audit-only 옵션. 실패 항목을 보고하지만 종료 코드로 차단하지 않는다.
- 정상 검증은 옵션 없이 실행하며 실패 항목이 하나라도 있으면 실패한다.
- Playwright와 설치된 Chrome 필요. 스크립트는 자동 설치하지 않는다.
- 경로가 다른 Chrome은 CHATBOT_TEST_BROWSER로 지정한다.
- 모든 요청을 가로채 로컬 static 파일만 제공한다.
- 외부 CDN은 차단하고 운영/AI/DB/이메일/통계 요청은 보내지 않는다.
- 카드 레이아웃은 신뢰된 합성 DOM으로 만든다. 정화 함수를 무력화하지 않는다.
  따라서 이 테스트만으로 실제 서버 카드 HTML/외부 CDN/검색 정확성을 검증했다고 말하지 않는다.
- 첫 안내: ko/en/vi/zh × 320×812, 390×844, 768×1024, 1280×900, 812×375.
- 한국어 결과 카드: 문의 구분선, 더 보기, 글자 대비, 키보드 포커스, 200% 텍스트 확대.
- 글자 확대는 주요 요소의 CSS 텍스트 확대다. 실제 기기의 핀치 줌/OS 글자 크기 검사와 다르다.
- 출력에 체크별 결과와 임시 스크린샷 디렉터리가 표시된다.
- 일반 모드의 무작위 팁은 단위 테스트, 동작 줄이기의 팁 고정은 실제 브라우저에서도 검증한다.

테스트 스크린샷은 임시 폴더에만 저장하며 저장소나 운영 통계에 테스트 자료를 넣지 않는다.

## 남은 확인 사항 및 다음 판단

1. 실제 iPhone Safari / Android에서 키보드 열기, 음성 입력, OS 글자 확대,

2. 외부 글꼴 CDN이 느리거나 차단된 실제 환경에서의 글꼴 폴백·레이아웃 이동은
   별도 네트워크 성능 측정이 필요하다. swap 속성 적용만으로 CLS 개선을 단정하지 않는다.

   사용자가 작게 원한 디자인과 함께 판단해야 한다.
5. 일반 모드의 자동 팁에 별도 '멈춤' 조작은 아직 없다. reduced-motion 대응과 구분한다.
   향후 자동 갱신 콘텐츠의 완전한 접근성 검토 시 수동 멈춤/다음 팁 UI를 검토한다.
6. 대시보드 시각 개편·통계 지표 추가는 이번 범위에서 제외했다.
7. 이 문서의 검증 결과는 배포 전 로컬 검증 기준이다. 승인된 배포 후에는 운영 캐시 버전과 제공되는 파일을 별도로 확인한다.

## 후속 수정: 첫 안내·추천 질문·이메일 문의

사용자 스크린샷에 따라 첫 안내에서 기관 확인 문구를 제거하고, 통계 고지는 말풍선 아래 11px로 분리했다.
통계 수집 자체는 그대로이며 결과의 원문 확인 안내도 유지한다.
첫 문장·짧은 질문·개인정보 주의 순서, 기존 글꼴/캐릭터/국기/글라스를 유지한다.
유효한 질문 전송/재시도 시작 시 추천 질문은 자동으로 접힌다. 완료 후 자동으로 다시 펼치지 않으며 수동 펼치기를 제공한다.
문의 details 안에는 짧은 mailto 링크, 테두리 없는 복사 버튼, 선택 가능한 주소만 둔다.
긴 메일 앱 설명은 제거하되 메일에 대화 내용을 첨부하지 않는 동작은 유지한다.

근거: 실제 기업 서비스의 지원 절차를 복제한 것이 아니라 공개 디자인 시스템의 링크/보조 행동 원칙을 적용했다.
- Microsoft Fluent: 짧고 목적이 명확한 링크, 보조 행동은 시각적으로 조용한 버튼.
  https://fluent2.microsoft.design/components/web/react/core/link/usage
- IBM Carbon: 이메일 이동에는 링크, 복사처럼 상태를 바꾸는 행동에는 버튼.
  https://v10.carbondesignsystem.com/components/link/usage/

후속 검증: 프런트엔드/대시보드 116개, 로컬 Chrome UI 46항목.
운영 API·이메일·통계로 테스트 요청을 보내지 않는다.
브라우저의 전송은 로컬 응답으로 대체하며, CDN 차단 환경에서 실제 검색 결과/스켈레톤 렌더링 전체를 인증하는 테스트는 아니다.
위 후속 검증은 배포 전 로컬 결과다. 승인된 배포 후 운영 파일과 관리자 인증을 별도로 확인한다.

## 구조 개선: 시작 영역과 답변 보조 메뉴

### 계획과 참고 범위

사용자가 제공한 Gemini/ChatGPT 화면에서 답변 내용과 작은 보조 도구가 분리되어 있고,
입력창이 독립된 둥근 영역이라는 시각적 구성을 참고했다.
서비스 전체를 조사했거나 최신 제품 UI를 그대로 복제한 것이 아니다.
첨부 화면의 다크모드·모델 선택·추천하지 않은 기능·새 폰트는 도입하지 않았다.

1. 첫 말풍선을 배경 없는 시작 영역으로 전환: 20~22px 제목, 14px 설명, 기존 캐릭터.
2. 통계 고지는 11px 기본 접힘 details, 개인정보 주의는 입력창 아래와 aria-describedby.
3. 문의는 답변의 회색 표면/aria-live 밖, 같은 메시지 행 하단 오른쪽.
4. 펼친 문의는 메일 주소 링크와 복사 버튼. 큰 버튼/중복 주소/긴 설명 제거.
5. 네 언어, 작은 화면, 긴 번역, 글자 확대, 기존 자동 접기 및 요청 경로 검증.

### 제목 크기 검토와 쉼표 줄바꿈

사용자는 글씨 크기에 대한 의견을 요청하고, 첫 안내의 쉼표 뒤 줄바꿈을 요청했다.
제목 크기(모바일 20px/기본 22px)는 그대로 두고 한국어 첫 설명에만 명시적 개행을 넣었다.
textContent와 해당 요소의 white-space: pre-line을 사용하며, 답변·금액·주소의 쉼표는 변환하지 않는다.
모바일 18px/기본 20px 축소는 제안이며 아직 적용하지 않았다.
참고: Microsoft Fluent typography는 본문 14px와 부제 20px 등 계층을 구분한다.
https://fluent2.microsoft.design/typography
이는 ChatGPT/Gemini의 실제 글꼴 크기를 측정한 결과가 아니다.


### 첫 안내 장식·글자 크기 조정 (사용자 승인 후)

- 첫 안내 영역의 중복 캐릭터 이미지만 제거했다. 상단 제목 캐릭터와 답변 캐릭터는 유지했다.
- 첫 안내 제목은 화면 너비 390px 이하 18px, 그 외 20px로 줄였다. 설명은 14px이며 쉼표 뒤 줄바꿈을 유지했다.
