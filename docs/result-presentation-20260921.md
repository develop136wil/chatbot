# 결과 표시 정리 (2026-09-21)

- 자료 수정일은 카드 화면에서 제거한다. DB의 last_edited_time과 캐시 무효화
  데이터는 유지한다. 번역 미완료 경고와 실제 신청/정책 날짜는 제거하지 않는다.
- li의 첫 직접 텍스트 노드에서 쉼표 + 공백 + 문자로 시작하는 경우만
  불필요한 앞 쉼표를 제거한다. 금액/소수/문장 안 쉼표/HTML 자식은 보존한다.
  일반적인 맞춤법 자동 교정이나 원본 Notion/공유 텍스트 변경은 하지 않는다.
- 더 보기 버튼 크기는 13px/32px를 유지하고 결과 하단 중앙에 배치한다.
  원문 확인 안내와 피드백 사이에 놓인다.
  기존 '아래 더 보기에서...' 문구와 바로 앞 구분선만 제거한다.
  마지막 결과 안내는 유지한다.
- KO/EN/VI/ZH의 서버 생성 문구에만 적용한다.
- 브라우저에서 정리하므로 기존 캐시에도 적용하며 재색인/캐시 삭제가 없다.

검증: 로컬 Python 115개 + JavaScript 99개.
CI Redis 6개와 배포 후 정적 파일 일치는 별도 확인한다.
실제 모바일 시각 검증은 자동 테스트와 구분한다.
