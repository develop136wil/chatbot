07 · INPUT

어떻게 질문했나요?

수치를 읽기 전에

  • 새 질문은 같은 내용을 다시 입력해도 1건입니다. 같은 요청의 재전송은 중복 집계하지 않습니다.
  • 더 보기·인사·초기화 등은 질문 수에서 제외합니다. 유효성 검증 실패·HTTP 요청 제한·서버에 도착하지 않은 요청은 수집 범위 밖입니다.
  • 원문 연결률 = 원문을 누른 답변 수 ÷ 자료를 찾은 질문 수. 신청 완료·지원 수혜·정확도·만족도가 아닙니다.
  • 기록 없는 날짜는 0건으로 단정하지 않고 결측으로 표시합니다. 이용이 없었는지 수집이 중단됐는지는 별도 확인이 필요합니다.
  • 접수 후 미완료는 작업 실패 또는 통계 완료 기록 실패일 수 있습니다. 100% 수집·성공으로 해석하지 마세요.
  • 통계 저장 실패 수는 현재 서버 인스턴스의 참고값이며 전체 누락률이 아닙니다. 프런트엔드 클릭은 브라우저 종료·통신 실패로 누락될 수 있습니다.
  • 임시 세션은 30분 비활동 후 새로 시작합니다. 일별 세션 합계는 실제 사람 수나 기간 전체의 고유 세션 수가 아닙니다.
  • 통계 원문 기록은 90일, 일별 집계는 730일 보관합니다. 상세 기간 밖의 재분석은 제한됩니다.
